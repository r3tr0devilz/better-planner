Better Planner — design direction, revised

Kept as a page,
not a screen.

Traded the dashboard glass for the thing the video actually trusts most — pen and paper. Index cards for the day's top three, a ruled ledger for the task list, ink-stamped dots for each domain instead of a neon bar. Warm parchment with real grain, not a flat cream fill.

Fraunces · headings Source Serif 4 · body JetBrains Mono · data grain-textured paper Next.js + Supabase
01 — Palette

Parchment, ink, and two accent inks

One paper tone for the page, one lighter tone for cards sitting on it — like a card pulled from a folder. Stamp-red and fountain-blue split the accent duty instead of a single terracotta doing everything; moss reads as a pen check-mark, not a system-green.

02 — Typography

Set like a printed page

Fraunces stays — its slight wonk already reads as handwritten warmth — but now sits upright instead of italic-only, sized like a masthead. Body copy moves off a UI grotesk onto Source Serif 4, so descriptions read like prose, not app chrome. Mono is reserved for anything stamped: dates, streaks, hours.

05 — Why these calls

Decisions, not defaults

Why paper over glass?
You said so directly — and it fits: the video's creator writes a real daily journal by hand and calls pen-and-paper "one of the best ways to commit things to memory." Paper isn't a skin here, it's the material the source system already trusts most.
Why keep Fraunces instead of a fresh typeface?
Its wonk already read as handwritten warmth in the glass version — the paper revamp only needed to change how it's set (upright masthead sizes, not italic-only), not replace it. Body copy is what actually moved, onto Source Serif 4, so paragraphs read like print.
Why two accent inks instead of one terracotta?
A single warm accent on cream is the most common AI default going. Splitting stamp-red (urgent, primary) and fountain-blue (secondary, calmer) reads like an actual desk — red pen for corrections, blue ink for everything else — and avoids that one-note look.
